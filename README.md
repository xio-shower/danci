# 单词记忆本（Google 表格自动同步）

连接 Google 表格的简易英语单词与搭配记忆网页，无需后端服务器，打开即可使用。

## 核心功能

- **打开自动探测更新**：每次打开网页（以及切回标签页）自动拉取 Google 表格最新数据，对比新增 / 修改 / 移除的词条并自动合并到本地词库，同时保留个人学习进度。
- **点击发声 & 语音跟读**：
  - 点击单词、原句或雅思复用例句即可发声；
  - 支持切换 **美音 US / 英音 UK** 与 **1.0x / 0.75x 慢速跟读**；
  - 支持浏览器语音识别 **跟读检测**（Chrome / Edge / Safari）。
- **隐藏翻译 & 手动输入翻译自测**：
  - **列表记忆模式**：一键隐藏全部翻译，每张卡片支持直接输入中文翻译核对对错或点击偷看；
  - **卡片自测模式**：专注单卡测试，支持回车核对、模糊语义匹配（自动识别括号内的易错提示如 `非“报道”`）、以及「意思相近，算我答对」手动覆盖。
- **进度与筛选**：支持按 `全部 / 未掌握 / 需复习 / 已掌握 / 本次新增` 筛选、搜索、随机打乱。

## 使用方式

1. 确保关联的 Google 表格共享权限为 **「知道链接的任何人均可查看」**。
2. 直接通过 GitHub Pages 访问，或在本地双击打开 `index.html` 即可使用。
3. 如需更换其他 Google 表格，点击网页右上角设置图标粘贴新的表格链接即可。
